# Jasmini Sherje — Neumorphic Portfolio

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Run it locally
1. Unzip the downloaded folder.
2. Open `index.html` in Safari, Chrome, or Firefox.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **new public repository** (for example, `jasmini-portfolio`).
2. Upload `index.html` to the repository's root folder and commit the change.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish. The page will be available at a URL similar to:
   `https://YOUR-GITHUB-USERNAME.github.io/jasmini-portfolio/`

## Before sharing
In `index.html`, replace the demo links:
- `https://github.com/your-username`
- `https://www.linkedin.com/in/your-username/`
- `hello@example.com`

The page uses Google Fonts (DM Sans and Space Grotesk); if you're offline, it falls back to system sans-serif fonts.
